# Support

- **Getting started:** the [README](../README.md) covers installing the server and Mac app and connecting agents.
- **Reaching your server from your phone:** [Remote access](REMOTE-ACCESS.md).
- **The iPhone app:** [iOS](IOS.md). No server yet? Tap **Explore a demo workspace** on the Connection screen. Questions or feedback about the iPhone and iPad app: [info@extendedmind.studio](mailto:info@extendedmind.studio).
- **Something broken, or a question:** open an issue in this project's GitHub repository. Say what you did, what you expected, and what happened, with the app and server versions (Settings shows both). Never paste a token.
- **Security issues:** report privately; see [SECURITY.md](../SECURITY.md).
